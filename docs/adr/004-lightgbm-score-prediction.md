# ADR-004: LightGBMベースのスコア予測モデル

## ステータス

採用

## コンテキスト

Phase 3で9つの専門家AIエージェントを実装するにあたり、各エージェントが馬を評価するためのベースモデルを選定する必要があった。

要件:
- 10点満点のスコアを予測（回帰タスク）
- 訓練時間が短い（9つのモデルを繰り返し訓練）
- 特徴量重要度を取得可能
- カテゴリ特徴量を直接扱える

検討したオプション:
1. **LightGBM Regressor** - 高速な勾配ブースティング
2. **XGBoost Regressor** - 安定した勾配ブースティング
3. **Neural Network** - 深層学習ベース
4. **Random Forest** - アンサンブルベース

## 決定

**LightGBM Regressor** を採用する。

理由:
- **訓練速度**: XGBoostより2-3倍高速
- **特徴量重要度**: `feature_importances_`で容易に取得可能
- **カテゴリ対応**: ネイティブでカテゴリ特徴量をサポート
- **メモリ効率**: 大規模データでもメモリ使用量が少ない

## 影響

### ポジティブ
- 9エージェントの訓練が数分で完了
- 特徴量重要度による解釈性の確保
- ハイパーパラメータチューニングが容易

### ネガティブ
- 小規模データでは過学習のリスク（early_stoppingで対策）
- 時系列依存性をモデル自体は捉えない（TimeSeriesSplitで対策）
